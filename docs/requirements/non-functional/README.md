# Requisitos não funcionais

Um arquivo por característica da ISO/IEC 25010. O índice de todos os requisitos está na
[capa do SRS](../README.md#requisitos).

| Característica | Arquivo | Cobre |
| --- | --- | --- |
| `SEC` | [security.md](security.md) | Isolamento, transporte, cota, autorização, segredo e ambiente |
| `PERF` | [performance.md](performance.md) | Latência e tamanho de galeria |
| `REL` | [reliability.md](reliability.md) | Comportamento com a inferência indisponível |
| `FLEX` | [flexibility.md](flexibility.md) | Os dois ambientes de execução |
| `INTR` | [interaction.md](interaction.md) | Qualidade de uso do painel |

Compatibilidade, adequação funcional, manutenibilidade e segurança física não têm requisito próprio
nesta versão: nenhuma necessidade levantada caiu nelas.
